# 猜数字小游戏

一个用 Python 编写的命令行猜数字小游戏，单文件实现，代码带有详细中文注释，适合初学者学习。

## 游戏规则

1. 电脑随机生成一个 **1 到 100** 之间的整数；
2. 玩家通过键盘输入自己猜的数字；
3. 程序会提示"**大了**"或"**小了**"，帮助玩家缩小范围；
4. 直到猜中为止，程序会显示"恭喜你，猜对了！"并统计玩家**一共猜了几次**。

## 运行环境

- Python 3.x（Windows 上安装 Python 时记得勾选 "Add Python to PATH"）
- 不需要安装任何第三方库（只用到了 Python 自带的 `random` 模块）

## 如何运行（Windows 命令行）

1. 按下 `Win + R`，输入 `cmd`，回车，打开命令提示符；
2. 使用 `cd` 命令切换到项目所在文件夹，例如：

   ```cmd
   cd C:\Users\你的用户名\Desktop\guess-number-game
   ```

3. 输入以下命令运行游戏：

   ```cmd
   python guess_number_game.py
   ```

   （如果 `python` 命令无效，可以试试 `py guess_number_game.py`）

## 代码逻辑说明

程序只有一个文件 `guess_number_game.py`，核心逻辑如下：

| 步骤 | 说明 |
| ---- | ---- |
| 1 | 用 `random.randint(1, 100)` 生成随机答案 |
| 2 | 用变量 `count` 记录猜测次数 |
| 3 | 用 `while True` 循环不断接收玩家输入 |
| 4 | 用 `isdigit()` 检查输入是否为数字，防止程序因非法输入而崩溃 |
| 5 | 用 `if / elif / else` 比较猜测值与答案，提示"大了"或"小了" |
| 6 | 猜中后用 `break` 跳出循环，输出总次数 |

## 游戏规则

1. 电脑随机生成一个 **1 到 100** 之间的整数；
2. 玩家通过键盘输入自己猜的数字；
3. 程序会提示"**大了**"或"**小了**"，帮助玩家逐步缩小范围；
4. 猜中后，程序会显示"恭喜你，猜对了！"，并统计玩家**一共猜了几次**。

## 运行环境

- Python 3.x
  - Windows 安装时记得勾选 **"Add Python to PATH"**；
  - macOS / Linux 通常已预装 Python 3，可运行 `python3 --version` 检查。
- 无需安装任何第三方库，只用到了 Python 自带的 `random` 模块。

## 快速开始

### Windows（用 CMD 命令行启动）

下面以本项目的实际路径 `D:\Users\ASUS\Desktop\exercise` 为例，一步步演示。

#### 第 1 步：打开命令提示符（CMD）

任选一种方式：

- **方式一（推荐）**：按下 `Win + R`，在弹出的"运行"窗口里输入 `cmd`，点击"确定"或直接回车；
- **方式二**：点击屏幕左下角"开始"菜单，搜索 `cmd` 或"命令提示符"，点击打开；
- **方式三**：在项目文件夹的地址栏里直接输入 `cmd` 后回车，会自动打开 CMD 并定位到该文件夹（可以跳过第 2、3 步）。

#### 第 2 步：切换到 D 盘

打开 CMD 后，默认通常在 `C:\Users\你的用户名` 下。由于本项目在 **D 盘**，需要先切换盘符，输入：

```cmd
D:
```

回车后，命令行提示符会变成以 `D:\>` 开头。

#### 第 3 步：进入项目文件夹

使用 `cd` 命令切换到项目所在文件夹：

```cmd
cd D:\Users\ASUS\Desktop\exercise
```

回车后，提示符会变成 `D:\Users\ASUS\Desktop\exercise>`，说明已经进入项目目录。

> 提示：路径较长或含空格时，可以用双引号包起来，例如 `cd "D:\Users\ASUS\Desktop\exercise"`。

#### 第 4 步：确认文件是否存在（可选）

输入下面的命令，查看当前文件夹里有没有游戏文件：

```cmd
dir
```

如果能看到 `guess_number_game.py`，说明目录正确，可以继续下一步。

#### 第 5 步：运行游戏

输入以下命令并回车：

```cmd
python guess_number_game.py
```

出现下面的欢迎界面，就说明运行成功了：

```
==============================
欢迎来到猜数字小游戏！
我已经想好了一个 1 到 100 之间的数字，快来猜猜吧！
==============================
请输入你猜的数字（1-100）：
```

#### 命令无效怎么办？

- 如果提示 `'python' 不是内部或外部命令`，说明 Python 没有加入 PATH。可以改用 `py` 命令运行：

  ```cmd
  py guess_number_game.py
  ```

- 如果两个命令都不行，请重新安装 Python，并在安装时勾选 **"Add Python to PATH"**，然后关闭并重新打开 CMD 再试。

## 代码逻辑说明

程序只有一个文件 `guess_number_game.py`，核心逻辑如下：

| 步骤 | 说明 |
| ---- | ---- |
| 1 | 用 `random.randint(1, 100)` 生成随机答案 |
| 2 | 用变量 `count` 记录猜测次数 |
| 3 | 用 `while True` 循环不断接收玩家输入 |
| 4 | 用 `isdigit()` 检查输入是否为数字，防止程序因非法输入而崩溃 |
| 5 | 用 `if / elif / else` 比较猜测值与答案，提示"大了"或"小了" |
| 6 | 猜中后用 `break` 跳出循环，输出总次数 |

## 常见问题

**Q：输入非数字（如字母、空格）会怎样？**
A：程序会提示"输入无效，请输入一个整数哦！"，不会崩溃，也不会计入猜测次数。

**Q：输入 1 到 100 之外的数字会怎样？**
A：程序按数值大小正常比较并给出提示，不影响游戏进行。

## 小知识：Markdown 与 README 是什么？

- **Markdown（.md）** 是一种轻量级标记语言，用简单的符号（如 `#` 表示标题、`-` 表示列表、反引号表示代码）就能写出排版漂亮的文档，被 GitHub 等平台广泛支持。
- **README** 是一个项目的"说明书"，通常放在项目根目录，用来介绍项目是做什么的、怎么安装、怎么运行、文件结构如何等，让别人（和未来的自己）能快速看懂并使用这个项目。
